# CRT Oscilloscope

Веб-прототип аналогового осциллографа на three.js: честная эмуляция поведения трубки — развёртка, триггер, послесвечение люминофора, X-Y режим.

## Статус

Прототип. Ядро вынесено в чистый JS без зависимости от three.js, потому что цель — проверить, переносима ли модель прибора на другой рендер (в том числе Android). Рендер-слой — observeable-обёртка над состоянием ядра.

## Архитектура

```
core/          модель прибора, чистый JS, без three.js
├── state.js    приборное состояние: калиброванные TIME/DIV и VOLTS/DIV, DEFAULTS, sweepWindow
├── signal.js   V(t): waveform, шум, DC/AC-связь входа и отдельная связь тракта триггера
├── trigger.js  развёртка и триггер: advanceSweep, fireTrigger, isBlanked, armSingle (AUTO/SINGLE)
├── fft.js      bandValues — спектр по полосам для управления амплитудой
└── mesh.js     buildTrace — геометрия кривой из отсчётов
app.js         three.js: сцена, постобработка, панель, WebAudio
vendor/        локальные three.js и jsm-модули (без CDN)
```

Ключевое разделение: **`core/` не импортирует three.js**. Это то, ради чего проект затевался — сигнал, развёртка и триггер живут независимо от способа отрисовки.

## Что эмулируется

- **Развёртка с триггером** — запуск по фронту, удержание уровня, перезапуск в AUTO при пропадании сигнала, одиночный пуск в SINGLE.
- **Отдельная связь тракта триггера** — AC/DC для триггера независим от AC/DC входа, как на настоящем приборе.
- **Плавные ручки вне калибровки** — VARIABLE и CAL/UNCAL влияют на эффективный VOLTS/DIV.
- **Гашение экрана (blanking)** — экран пуст, когда развёртка не идёт и триггер не взведён.
- **Гистограмма/спектр** — амплитуда сигнала управляется полосами FFT.
- **X-Y режим** — фигурами Лиссажу.

## Запуск

Отдать текущую папку любым статическим сервером (модули подключаются через ES import):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Сборки и зависимостей нет — three.js лежит в `vendor/`, чтобы прототип запускался одним файлом-сервером и без сети.
